# Phase 4B-5: Jammu & Kashmir Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** J&K's assemblies (2008/2014 on the 1995 boundaries, 87 seats incl. Ladakh; 2024 on the 2022 boundaries, 90
seats) on the site with real ECI results, regions and person links; 2024 at current-track depth; then on production.

**Architecture:** The Maharashtra pipeline plus two small hooks: per-election delimitation/reserved overrides in the
registry, and per-delimitation districts files in `regions-cli`. A new map for 2024; the old map republished under its
true era name.

**Tech Stack:** TypeScript scraper (vitest), PostgreSQL seeds, S3 media, React frontend.

**Spec:** `docs/superpowers/specs/2026-10-07-phase4b-jk-design.md`. Template: `docs/superpowers/plans/2026-10-06-phase4b-maharashtra.md`.

## Global Constraints

- Seeds fill-only / run-once; shipped seeds unchanged (except `seed_party_symbols.sql`, `setup.sh`,
  `seed_party_lineage.sql`); units v1-v5 frozen, J&K units → `units-9.json` → v6.
- Ids `a0130000-0000-4000-8000-00000000<year>`; prefix `JK_VS<yy>_`; state id 13.
- 2008/2014: delimitation `'1995'`, 87 seats, majority 44. 2024: `'2022'`, 90 seats, majority 46.
- Map files never edited in place: `jk_ac_1995.geojson` (copy of `jk_ac_2008.geojson`), `jk_ac_2022.geojson` (new);
  `/geo/jk_ac_2008.geojson` and `/geo/jk_ac.geojson` redirect to `jk_ac_1995.geojson`.
- Leaders, parties and units lists user-approved before seeding.
- Production: Neon backup first; setup via the direct host with TCP keepalives until two clean runs; Render only if
  backend files change.

## Review Focus

1. **No cross-era history.** Expected: a 2024 seat page shows no 2014 result even where the seat name is unchanged;
   2014 seat pages show 2008.
2. **Ladakh seats.** Expected: 2008/2014 have Nubra, Leh, Kargil, Zanskar under region Ladakh; 2024 has none.
3. **Other states unaffected by the registry/regions hooks.** Expected: regenerating every state's seeds and region
   seeds produces no diff.
4. **Maps.** Expected: 2008/2014 dashboards colour 87 seats, 2024 colours 90; old map URL still loads.
5. **Party ids.** Expected: JKNC/JKPDP/JKNPP/JKPC existing ids reused; new parties (JKAP, DPAP, AIP…) get grey records
   without duplicates.
